## 2. Rules (do not break)

1. Every workflow JSON imports with `active:false`; run `python3 -I tools/n8n_audit.py workflows` before every commit; 0 blocked required.
2. No secrets, tokens or credential IDs in any file. Credentials are referenced by name only.
3. Change workflows ONLY by editing `social/build_workflows.py`, then `python3 social/build_workflows.py`. Never hand-edit `workflows/soc-*.json`.
4. Nothing publishes, sends to the public, bids or spends without the owner's approval. `auto_publish` stays false.
5. Keep SOC-07 (publishing) OFF until the owner approves a successful test.
6. Content rules live in `BRAND` in the build script: only promote `services_confirmed`; never invent prices, reviews, stats or certifications; local partners do the cleaning; no faces; real photos only.
7. Merge flow: branch, PR, squash-merge into `main`, then run `Documents\Import-Workflows.cmd` on the PC.
8. Do not claim a workflow works until it has run successfully in n8n.
